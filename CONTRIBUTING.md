# Contributing to OSS E-Learning

Terima kasih atas minat Anda untuk berkontribusi pada proyek OSS E-Learning! 🚀

## Cara Berkontribusi

1. **Fork Repositori**
2. **Buat Branch Baru**:
   ```bash
   git checkout -b feature/nama-fitur-keren
   ```
3. **Commit Perubahan Anda**:
   Gunakan format commit konvensional:
   - `feat: tambah modul kuis interaktif`
   - `fix: perbaiki bug audio player`
   - `docs: update panduan self-hosting`
4. **Push ke Branch Anda**:
   ```bash
   git push origin feature/nama-fitur-keren
   ```
5. **Buka Pull Request (PR)**:
   Jelaskan apa yang Anda ubah dan sertakan screenshot/video jika berhubungan dengan antarmuka pengguna (UI).

## Standar Kode
- Pastikan kode bersih, mengikuti aturan linter dan formatter yang ada.
- Tambahkan unit test / integration test bila menambahkan fitur inti baru.
